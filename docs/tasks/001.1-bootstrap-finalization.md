# Task 001.1 — Bootstrap Finalization

## Objective

Finalize the initial project bootstrap without introducing new application features.

The repository must be ready to merge `feature/project-bootstrap` into `main` and then begin the first real FHIR development task.

## Context

Repository:

`healthcare-ai-interoperability-lab`

Current branch:

`feature/project-bootstrap`

This project is independent. Do not import, reference, or reuse CareFlow application code.

The architecture is intentionally incremental:

- Java 21 / Spring Boot for healthcare interoperability.
- Python / FastAPI for future AI/ML services.
- HAPI FHIR as local FHIR infrastructure.
- PostgreSQL as infrastructure.
- Docker Compose for local infrastructure.

Do not create `ai-service`, `agent-service`, HL7 v2 components, Epic integrations, Oracle Health integrations, RAG, agents, MCP, or other future components in this task.

### 5. Run verification

Run:

```bash
java -version
```

Verify Java 21.

Run:

```bash
cd services/fhir-integration-service
mvn test
```

Expected result:

`BUILD SUCCESS`

Run from repository root:

```bash
docker compose -f infra/docker/docker-compose.yml config
```

It must complete without configuration errors.

Start infrastructure:

```bash
docker compose -f infra/docker/docker-compose.yml up -d
```

Verify containers are running.

Verify HAPI FHIR:

```http
GET http://localhost:8080/fhir/metadata
```

Expected:

- HTTP 200
- FHIR `CapabilityStatement`
- FHIR R4 / `4.0.1` declared by the current HAPI configuration

Verify application health:

```bash
cd services/fhir-integration-service
mvn spring-boot:run
```

Then:

```http
GET http://localhost:8081/actuator/health
```

Expected:

```json
{
  "status": "UP"
}
```

Stop the application after verification if desired. Infrastructure may remain running.
